# AVTOMOD Garage Prototype

Отдельный статический визуальный прототип. Откройте `index.html` в браузере.

Тексты, услуги, контакты и фотография взяты из проекта, но не синхронизируются с Django. Главная, услуги и контакты работают как отдельные HTML-страницы. Остальные разделы и форма заявки ведут на локальный Django-сайт по адресу `http://127.0.0.1:8001/`; для их работы необходимо запустить сайт на этом порту. Сам прототип не отправляет заявки.
